# Primeiro consulta a API

Este projeto cria um servidor HTTP simples usando Node.js que tem como função buscar dados de uma API de clima.

## Como usar

### Pré-requisitos
- Node.js instalado na sua máquina (versão 12 ou superior).

### Instruções

1. Clone o repositório ou baixe o código-fonte.
2. Navegue até o diretório do projeto.
3. Crie e inclua no arquivo .env suas variáveis (chave API e URL):
4. Rode o comando:
   ```bash
   npm install
   ```
   Para instalar as dependências.
5. Certifique-se de que o arquivo `index.html` está presente no diretório.
6. Execute o servidor com o comando:
   ```bash
   npm start
   ```
7. Isso irá abrir a porta `http://localhost:4200`.
8. Abra o `index.html` da pasta para fazer as requisiçoes.
